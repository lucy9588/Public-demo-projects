Project 01

Azul Java Provision Automation

This project automates Azul Java provisioning across target servers through a controlled request and execution workflow. The process starts with a user request containing the target server, environment, Java version, and installation type. The platform then validates required fields, checks server and environment eligibility, resolves the package source and runtime inventory, and triggers the provisioning automation through Jenkins / AAP. On the target server, the workflow installs Azul Java, configures environment settings such as JAVA_HOME, profile, alternatives, or symlinks, and verifies the installation by checking the expected Java version. The final result is returned with success or failure output, making Java provisioning more standardized, auditable, and consistent across environments.
